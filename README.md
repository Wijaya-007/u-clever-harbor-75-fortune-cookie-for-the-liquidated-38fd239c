A tiny Node 22 (stdlib-only) program that writes one fortune-cookie message for a freshly liquidated crypto trader to `/output/entry.txt` and prints it to stdout.

## Run

```sh
node main.ts
```

## The line

> Your next trade will be your best one. The cookie has no data to support this, but neither did you.
